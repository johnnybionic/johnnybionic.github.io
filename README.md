# West Charlton Residents' Association website

This is a simple static HTML website that is intended to provide basic information for those living in the West Charlton (SE7 in London) area.

The association has no membership fees and thus needs a web presence with minimum costs. 

## Using goatcounter

Calling goatcounter directly often gets blocked by the browser - it's either treated as adware, or causes problems due to cross-origin (i.e. it's a different domain from where the static HTML is served).

To get round this, a CNAME is added to our host domain, e.g. stats.westcharltonra.info, and this redirects to goatcounter.
